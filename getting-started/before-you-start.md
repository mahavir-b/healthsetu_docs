# Before you start — paper & Excel exercise

HealthSetu works best when your **operations are named on paper first**. Opening the website before that feels daunting because the screens ask for decisions you have not made yet.

This pack is for **owners, medical officers, and department heads**. Do it with a pen, then Excel, then the software.

## How to use this pack

| Step | What you do | Time |
|------|-------------|------|
| **1. Print** | Print the module worksheet(s) for what you bought | 5 min |
| **2. Write** | Fill blanks in a meeting — real people, real places, real machines | 45–90 min per module |
| **3. Excel** | Copy clean answers into the CSV / Excel templates | 30–60 min |
| **4. Software** | Type from Excel into Hospital setup / module admin — no inventing live | go-live session |

<div class="callout callout--tip">
  <strong>Rule:</strong> write what is true today. Do not invent an ideal hospital. Blank cells mean “skip that setup step for now.”
</div>

## Who should sit in the room

| If you bought… | Bring |
|----------------|-------|
| **HRSetu** | Owner + one person who knows every site and job title |
| **RakhtSetu** | Medical officer + lab in-charge + camp / counseling lead |
| **CareSetu** | Clinic admin + one doctor + front desk lead |
| **SupplySetu** | Store / purchase lead + biomedical (if assets) |
| **SwasthaSetu** | OHC doctor + HR (employers / fitness rules) |

## Order (if you bought more than one)

```text
1. Places & people (HR)          ← always first when HR is in the contract
2. Clinic or blood bank or OHC   ← the clinical module you run
3. Supply / stores               ← when stock & vendors matter
```

## Mindmap (draw once on A3 / whiteboard)

```text
                 [ Your organisation name ]
                            |
     ┌──────────────────────┼──────────────────────┐
 Places of work        How people work         How care / lab runs
     |                      |                         |
 Branches / sites      Shifts & holidays      Tests / OPD / stores
 Who works where       Check-in rules?        Machines & partners
 Departments → titles  Join-day papers        Labels & QC
```

## After the paper is done

1. Hand the filled sheets to the person who will type into HealthSetu.
2. Follow <a href="#" data-hs-route="getting-started/admin-setup">Go-live checklist (admins)</a>.
3. Only then open Hospital setup (`/setup`) and module admin screens.
