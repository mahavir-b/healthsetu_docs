# Glossary

| Term | Meaning |
|------|---------|
| **ABHA** | Ayushman Bharat Health Account — the national health ID. Donors and patients can be linked to it. |
| **Asset** | Equipment tracked individually (centrifuge, fridge, monitor) — not consumable stock. |
| **BMW** | Biomedical waste, logged under the BMWM Rules 2016. |
| **Capability** | A single permission inside a role. |
| **Care plan** | A ready-made treatment plan for an illness, installed with a department template. |
| **Component** | A blood product separated from whole blood (PRBC, FFP, platelets, cryo). |
| **Counsellor board** | Where patient decisions on doctor recommendations are recorded. |
| **Crossmatch** | Compatibility test between a donor unit and a patient before issue. |
| **Department template** | A pack of illnesses, medicines, and care plans for a clinic department. |
| **FEFO** | First expiry, first out — stock with the earliest expiry is issued first. |
| **Fee item** | A standard charge (consultation, procedure, service) used in billing. |
| **Module** | A product inside HealthSetu: Core, RakhtSetu, SupplySetu, HRSetu, CareSetu, SwasthaSetu. |
| **My Work** | The menu group with Inbox, Tasks, and your self-service screens. |
| **OHC** | Occupational health centre — run with SwasthaSetu. |
| **OPD** | Outpatient department — the doctor’s visit workspace in CareSetu. |
| **Organisation (tenant)** | Your clinic, blood bank, or hospital on HealthSetu, with its own URL and database. |
| **PEM** | Pre-employment medical exam. |
| **Put-away** | Moving received goods to their store location so they show in stock. |
| **Role** | A named bundle of capabilities (Clinic doctor, HR manager, …). |
| **Sitting** | One session of a multi-session procedure course. |
| **TTI** | Transfusion-transmissible infections screened on every unit. |
| **UHID** | Unique health ID the clinic gives each patient (for example `C-000001`). |
| **Work clearance** | A check an employee needs before they can check in for work. |
