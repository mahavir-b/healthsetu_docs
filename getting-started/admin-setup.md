# Go-live checklist (admins)

Use this list before staff start working in HealthSetu. Tick each item in order; later steps depend on earlier ones.

<div class="callout callout--tip">
  <strong>Do this first:</strong> print and fill the
  <a href="#" data-hs-route="getting-started/before-you-start">Before you start — paper &amp; Excel</a>
  worksheets for each module you bought. Do not invent workplaces, machines, or fees live in the browser.
</div>

## 1. Organisation (Core)

- [ ] **Profile** — name, address, phone, and email (these print on letterheads)
- [ ] **Branding** — app name, colour, logo
- [ ] **Email server** — SMTP saved and a test email received
- [ ] **Roles** — import the recommended roles for your modules (the Roles tab warns when some are missing)
- [ ] **Users** — one account per person; no shared logins
- [ ] Optional: **Communications** (WhatsApp), **Payment QR**, **Barcodes**, **ID cards**

See <a href="#" data-hs-route="core/users-roles">Users & roles</a> and <a href="#" data-hs-route="core/settings">Email, branding & settings</a>.

## 2. HRSetu

- [ ] Workplaces and departments
- [ ] Employees added (doctors and nurses too — CareSetu reads doctors from HR)
- [ ] Shift roster for the first week
- [ ] Leave policies

## 3. CareSetu

- [ ] Department templates installed
- [ ] Doctors registered with fees
- [ ] Schedules saved for every doctor
- [ ] Fee items checked

See <a href="#" data-hs-route="caresetu/setup">Clinic setup & reports</a>.

## 4. SupplySetu

Stock stays empty until these exist, in this order:

- [ ] **Locations** (Main store, OT, Blood bank fridge, …)
- [ ] **Vendors**, with their document checklist
- [ ] **Catalog** items
- [ ] Opening **Stock**

See <a href="#" data-hs-route="supplysetu/catalog-stock">Catalog, stock & locations</a>.

## 5. RakhtSetu

- [ ] Barcode templates for bag, component, and sample labels test-printed on the real printer
- [ ] Institutions (partner hospitals and blood banks)
- [ ] QC checklist templates by cadence
- [ ] Payment QR, if you collect payment for blood requests

## 6. SwasthaSetu

- [ ] Departments and job titles
- [ ] Medical tests and test requirements
- [ ] BMW agency and MOU

See <a href="#" data-hs-route="swasthasetu/overview">SwasthaSetu overview</a>.

## 7. First day

- [ ] Each user signs in and changes their temporary password
- [ ] Each user checks they see only their screens
- [ ] Trainers walk staff through <a href="#" data-hs-route="getting-started/by-role">Guides by role</a>
