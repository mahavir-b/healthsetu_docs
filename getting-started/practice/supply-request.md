# Hands-on: Inventory requester

**Role:** `request`  
**Practise on:** `https://{your-org}.healthsetu.com/`  
**Login:** requester login  
**Time:** about 10 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Open only the staff portal above — not a module Static Web App URL.
</div>

## You will learn

- Raise a stock request
- See approval status

## Step by step

1. [ ] Sign in at `https://{your-org}.healthsetu.com/`
2. [ ] Open **Request inventory** (`/inventory/request`)
3. [ ] Request a small qty (e.g. 5 boxes gloves) for OT store → Submit
4. [ ] Note you typically **cannot** approve your own request
5. [ ] Ask inventory manager / supply admin to approve
6. [ ] Sign out

## Screens this role uses

- `/inventory/request`

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which sidebar items are yours (and which are not)
