# Hands-on: OHC medical officer

**Role:** `ohc_medical_officer`  
**Practise on:** `https://{your-org}.healthsetu.com/`  
**Time:** about 25 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Use only the staff portal — not a module Static Web App URL.
  Skip this path if your organisation did not enable the module for this role.
</div>

## You will learn

- Run exams and OPD
- Record fitness decisions
- Review medical panels

## Step by step

1. [ ] Sign in at `https://{your-org}.healthsetu.com/`
2. [ ] `/ohc` · `/ohc/opd`
3. [ ] `/ohc/pre-employment` or `/ohc/periodic-medical` — open a case
4. [ ] Record / complete exam steps per SOP
5. [ ] Fitness decision if required
6. [ ] `/ohc/audiometry` / vaccination if used
7. [ ] Sign out

## Screens this role uses

- `/ohc/opd`
- `/ohc/pre-employment`
- `/ohc/periodic-medical`
- `/ohc/health-checkup`
- `/ohc/audiometry`

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which sidebar items are yours (and which are not)
