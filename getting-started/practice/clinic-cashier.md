# Hands-on: Clinic cashier

**Role:** `clinic_cashier`  
**Practise on:** `https://{your-org}.healthsetu.com/`  
**Login:** your cashier login  
**Time:** about 15 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Open only the staff portal above — not a module Static Web App URL.
</div>

## You will learn

- Open clinic billing (or Billing desk if your org uses the Billing module)
- Charge a consult fee and mark paid

## Step by step

1. [ ] Sign in at `https://{your-org}.healthsetu.com/`
2. [ ] Open **Billing** (`/clinic/billing` — or `/billing` if Care billing is hidden because Billing module is on)
3. [ ] Find the patient who finished OPD (Test Patient One)
4. [ ] Charge **New consultation** (₹500 in training orgs) — add Dressing if done
5. [ ] Collect **Cash** (or UPI if trainers set Payment QR)
6. [ ] Confirm receipt / paid status
7. [ ] Confirm you cannot edit doctor schedules
8. [ ] Sign out

## Screens this role uses

- `/clinic/billing`
- `/billing (if BILLING module)`

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which sidebar items are yours (and which are not)
