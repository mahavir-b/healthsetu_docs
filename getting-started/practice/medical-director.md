# Hands-on: Medical director

**Role:** `medical_director`  
**Practise on:** `https://{your-org}.healthsetu.com/`  
**Login:** medical director login  
**Time:** about 25 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Open only the staff portal above — not a module Static Web App URL.
</div>

## You will learn

- Institutions
- Equipment
- Workflows / questionnaire
- Clinical dashboards

## Step by step

1. [ ] Sign in at `https://{your-org}.healthsetu.com/`
2. [ ] `/dashboard` and `/dashboard/compliance` open
3. [ ] `/hospitals` — open or add a training institution
4. [ ] `/admin/equipment-configuration` — confirm equipment list
5. [ ] `/admin/workflows` — review donor questionnaire (approve only if you are the approver)
6. [ ] Browse QC / requests dashboards
7. [ ] Do **not** run blood data reset in training unless instructed
8. [ ] Sign out

## Screens this role uses

- `/dashboard`
- `/hospitals`
- `/admin/equipment-configuration`
- `/admin/workflows`
- `/dashboard/qc`

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which sidebar items are yours (and which are not)
