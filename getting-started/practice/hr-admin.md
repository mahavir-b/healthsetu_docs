# Hands-on: HR admin

**Role:** `hr_admin`  
**Practise on:** `https://{your-org}.healthsetu.com/`  
**Login:** HR admin login  
**Time:** about 30 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Open only the staff portal above — not a module Static Web App URL.
</div>

## You will learn

- Maintain workplaces
- Hire an employee
- Mark attendance
- Open payroll screens

## Step by step

1. [ ] Sign in at `https://{your-org}.healthsetu.com/`
2. [ ] `/workplaces` — open MAIN campus
3. [ ] Confirm shifts and departments exist
4. [ ] `/employees` → **Hire** a training employee (or open an existing one)
5. [ ] Set status **Active**
6. [ ] `/attendance` — mark someone present today
7. [ ] `/leave` — open the list
8. [ ] `/salary` · `/statutory` · `/hr/dashboard` · `/document-library` browse
9. [ ] Sign out

## Screens this role uses

- `/workplaces`
- `/employees`
- `/employees/hire`
- `/attendance`
- `/leave`
- `/salary`
- `/hr/dashboard`

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which sidebar items are yours (and which are not)
