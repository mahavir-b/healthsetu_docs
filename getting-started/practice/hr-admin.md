# Hands-on: HR admin

**Role:** `hr_admin`  
**Sign in at:** `https://{your-org}.healthsetu.com/`  
**Login:** your login for this role  
**Time:** about 30 minutes

<div class="callout callout--tip">
  Sign out of any other account first. Work only in the staff portal. Follow the <strong>left menu</strong> and on-screen buttons (Add, Edit, Save, Refresh) — you do not need to type web addresses.
</div>

## You will learn

- Workplaces
- Hire
- Attendance

## Step by step

1. [ ] Sign in
2. [ ] Left menu → **Administration** → **Setup** → **Workplaces** — open MAIN → review shifts
3. [ ] Left menu → **People** → **Employees** → click **Hire** / **Add**
4. [ ] Fill workplace, department, role → set status **Active** → **Save**
5. [ ] Open the employee row (name click or **Edit**)
6. [ ] Left menu → **People** → **Attendance** — mark someone present → **Save**
7. [ ] Left menu → **People** → **Leave** — open the list
8. [ ] Left menu → **People** → **Shift roster** — open once
9. [ ] Open **Salary**, **Statutory**, **HR dashboard**, **Document library** once each
10. [ ] Sign out

## Where to click in the UI

- **Administration** → **Setup** → **Workplaces**
- **Employees** → **Hire** → **Save**
- **Attendance** / **Leave** / **Shift roster**

## Done when

- [ ] You finished every step without an unexplained error banner
- [ ] You know which left-menu items are yours (and which are hidden)
