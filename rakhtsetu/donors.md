# Donors

Use **Donors** to register walk-in and camp donors, update details, and see donation history.

## Register a donor

1. Open **Donors** → **Add** / Register.
2. Enter name, contact, gender, date of birth / age, and blood group if already known.
3. Capture consent and questionnaire answers as your SOP requires.
4. Save — note the donor number for the collection desk.

## Everyday tips

- Search by phone or donor number before creating a duplicate.
- Update address / phone when the donor corrects it — issue letters and recalls use this data.
- Deferral reasons should be clear so the next camp team does not re-bleed incorrectly.

<div class="callout callout--tip">
  Camp days: pre-register organisers’ lists the day before so the counter only confirms identity.
</div>
