# Processing

**Processing** (component separation) turns whole blood into components and tracks which units are ready for testing / stock.

## Typical steps

1. Open **Processing** / separation queue.
2. Select units ready to separate.
3. Record components produced (PRBC, FFP, platelets, etc. as per your licence).
4. Print component labels if prompted.
5. Send components forward to testing / QC as your workflow requires.
