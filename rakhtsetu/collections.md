# Collections

**Collections** records the bleed: bag, volume, time, phlebotomist, and links the unit into processing.

## Record a collection

1. Find the donor (from camp queue or walk-in).
2. Enter bag / unit identifiers as labelled.
3. Capture volume, start/end time, and any adverse reaction notes.
4. Save — the unit should appear for **Processing**.
