# Testing & crossmatch

Lab screens cover grouping, TTI / ELISA workflows, and **crossmatch** before issue.

## What staff do here

- Enter or import test results for units
- Mark reactive / non-reactive as per SOP
- Run crossmatch for a patient request
- See pass / fail summary before marking compatible

## Crossmatch decision

1. Open the patient / request.
2. Select donor unit(s).
3. Complete each required test row.
4. Use **Mark Compatible** or **Mark Incompatible** only after the summary matches your SOP.
5. Incompatible units must not proceed to issue.

## Crossmatch performance

Open **RakhtSetu dashboard → Crossmatch** to see crossmatch success, average turnaround, the turnaround trend, and the compatible / incompatible mix for a date range.
