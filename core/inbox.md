# Inbox & My Work

**My Work** is where items waiting on *you* land — approvals, follow-ups, sync items, or HR self-service links.

## Everyday use

1. Open **Inbox** / **My Work** from the left menu after login.
2. Open the newest item first.
3. Complete the action (approve, dismiss, open linked record).
4. Refresh if a colleague just assigned something.

## What you might see

| Item type | What to do |
|-----------|------------|
| Task / staff task | Open and mark done when finished |
| HR leave / document | Action from My HR if linked |
| Clinic sync document | Review in CareSetu Sync Inbox |
| Preference / account | Update password or display options |

<div class="callout callout--tip">
  Start every shift with Inbox. It prevents missed approvals sitting overnight.
</div>
