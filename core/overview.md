# Core — organisation portal

Core is the **front door** of HealthSetu. Every staff member signs in here. Organisation admins also manage users, roles, barcodes, email, and branding.

## What clients use Core for

- One login for all subscribed modules
- Invite and disable users safely
- Give each person only the screens they need (roles & capabilities)
- Print barcodes and ID-style labels from shared templates
- Configure SMTP / WhatsApp / payment QR so the clinic can message patients and vendors
- Work inbox for tasks that cross modules

## Who should open Core admin screens?

| Person | Typical Core work |
|--------|-------------------|
| Organisation admin | Users, roles, email, WhatsApp, barcodes, ID cards, branding |
| Department head | Review who has access in their area |
| All staff | Inbox, password, preferences |

Most clinical work happens inside RakhtSetu, SupplySetu, HRSetu, CareSetu, or SwasthaSetu — not in Core admin tabs.
