# Email, branding & settings

Admins configure how the organisation looks and how messages leave the system.

## What you can configure

| Area | Effect for staff / patients |
|------|-----------------------------|
| Branding / letterhead | Names and logos on portal and some prints |
| SMTP email | Invites, vendor mails, clinic notices |
| WhatsApp (if enabled) | Patient / vendor messaging via Comms |
| Payment QR | Shown where patients pay at counter |
| Functionality flags | Which modules appear for the organisation |

## Good practice

- Send a **test email** after changing SMTP.
- Keep letterhead address and phone accurate — CareSetu print and certificates use organisation identity.
- Changes usually apply on the **next** request or login; tell staff if something looks cached.

<div class="callout callout--tip">
  Clinic letterhead gaps (name only, no address) are almost always empty organisation / clinic settings — fill them here or in the clinic settings screen when available.
</div>
