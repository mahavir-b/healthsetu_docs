# Patients

**Patients** is the clinic registry — search first, then register if new.

## Register or find a patient

1. Open **Patients**.
2. Search by name, phone, or UHID.
3. If new: Add patient (name, phone, gender, age / DOB, address as required).
4. Open the chart for visits, documents, and next steps (follow-ups).

## Next steps on the list

When a doctor planned a follow-up, reception may see **Next steps** with **Book slot** already prepared — use it so the follow-up stays linked to the earlier visit.

  Always search before creating. Duplicate patients split history and bills.
