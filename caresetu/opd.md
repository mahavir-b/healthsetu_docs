# OPD visit

**OPD** is the doctor (and nurse) workspace for today’s visits.

## Run a visit

1. Open **OPD** and select the arrived patient / appointment.
2. Capture vitals (skip empty fields — they stay off the print).
3. Enter complaint; apply a **care plan** when the specialty pack suggests one.
4. Review Rx, recommendations, and follow-up.
5. **Sign** the note when complete (unsigned prints show as draft).
6. Print summary for the patient when ready.

## Recommendations

Mandatory / advised / optional items go to the **Counsellor** board for patient decision when your clinic uses that flow. Doctors should not assume accept until counsellor records it.
