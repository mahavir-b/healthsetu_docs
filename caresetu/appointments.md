# Appointments & schedules

## Book an appointment

1. Open **Appointments** → Add (or Book slot from Next steps).
2. Choose patient, doctor, date, and a free time chip.
3. Set visit type / reason (follow-up reason is often prefilled).
4. Save — the slot shows as booked on the calendar / list.

## Arrival & status

Mark patients **Arrived** so they appear on the OPD list for the doctor. Use Reschedule / Cancel with a reason when your clinic requires it.

## Schedules (admin)

**Schedules** define each doctor’s working days and hours. Booking should only offer slots on working days — if a day is missing, fix the schedule, not the appointment by force. See <a href="#" data-hs-route="caresetu/setup">Clinic setup & reports</a>.
