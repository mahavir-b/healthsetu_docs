# Billing & print

## Visit billing

On the visit **Billing** tab (or **Billing** screen):

1. Confirm billable lines (consultation, sitting, consumables).
2. Use the fee item picker for standard rates.
3. Hand off to your organisation’s billing / payment process as configured.
4. Keep item name, qty, and rate clear for the cashier.

## Print

- Use **Print** / preview for visit summary, Rx, and consent copies.
- If the browser blocks pop-ups, use the **inline preview**.
- Unsigned notes print as **DRAFT – NOT VALID**.
- Letterhead comes from organisation / clinic settings — ask admin if address or phone is missing.
