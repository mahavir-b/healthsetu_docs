# Procedures & sittings

Procedure courses (laser, peels, etc.) are planned for **N sittings** with consent, checklists, and before/after photos.

## Create and run a course

1. From an accepted recommendation, **Create course**.
2. Capture **consent** (language, patient + witness signatures) — PDF lands on the chart.
3. For each sitting: book → checklist → **Start** (only on the booked day) → complete parameters → photos.
4. Interval rules may ask for a reason if you book sooner than the template allows.
5. Reschedule moves a sitting in one step when plans change.
